# SQL Task: Pagila Database

Этот проект содержит SQL-запросы для учебного задания на базе данных **Pagila**.

Pagila — это PostgreSQL-версия демонстрационной базы Sakila. Она моделирует видеопрокат: фильмы, актёров, категории, инвентарь, аренду, клиентов, адреса и города.

## Используемые таблицы

| Таблица | Назначение |
|---|---|
| `film` | Информация о фильмах |
| `inventory` | Экземпляры фильмов, доступные в магазинах |
| `rental` | Факты аренды фильмов |
| `payment` | Платежи за аренду |
| `actor` | Актёры |
| `film_actor` | Связь между фильмами и актёрами |
| `category` | Категории фильмов |
| `film_category` | Связь между фильмами и категориями |
| `customer` | Клиенты и их статус активности |
| `address` | Адреса клиентов |
| `city` | Города |

## Задачи

1. Вывести количество фильмов в каждой категории, отсортировав результат по убыванию.
2. Вывести топ-10 актёров, чьи фильмы арендовали чаще всего, в порядке убывания.
3. Определить категорию фильмов, на которую было потрачено больше всего денег.
4. Вывести названия фильмов, которых нет в инвентаре, без использования оператора `IN`.
5. Вывести топ-3 актёров по количеству фильмов в категории *Children*. Если у нескольких актёров одинаковое количество фильмов, вывести всех.
6. Вывести города с количеством активных и неактивных клиентов, отсортировав по количеству неактивных клиентов по убыванию.
7. Определить категории фильмов с наибольшим количеством часов аренды в каждом городе. Учитывать фильмы, названия которых начинаются с буквы `a`. Также обработать города, в названии которых есть символ `-`. Выполнить всё в одном запросе.
